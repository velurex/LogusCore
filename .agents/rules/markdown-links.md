# Markdown Links Rule

## Relative Links Policy

- **Exclusively Relative Links:** When creating or editing Markdown documents (`.md`), all links referencing project files, directories, and documentation must strictly use relative paths (e.g., `./docs/setup.md` or `../README.md`).
- **No Absolute Local Paths:** Absolute filesystem paths (such as `C:\...` or `/...`) must never be used in Markdown links.
