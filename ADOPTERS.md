## How to Register Your Adoption

We provide two simple ways to let us know you are using Logus Core:

### Option 1: Public Entry via Pull Request (Recommended for Open-Source & Public Projects)

1. Fork this repository.
2. Add your organization or project to the [Current Adopters](#current-adopters) table above in alphabetical order.
3. Submit a pull request with the title `chore: add <Project Name> to ADOPTERS.md`.

Please include:
* **Organization / Project:** The name of your product, team, or organization.
* **Category:** Primary domain (e.g., Mobile App, Accessibility, Healthcare, Research, IoT).
* **Use Case:** A brief 1-2 sentence description of how Logus Core is utilized.
* **Link:** A link to your website, repository, or store listing.
* **Contact / Reference (Optional):** GitHub handle or public contact.

### Option 2: Private / Confidential Adoption Form (For Proprietary or Pre-Release Apps)

If your project is closed-source, proprietary, or not yet publicly released, you can register confidentially. This allows us to track adoption metrics and understand ecosystem needs without disclosing your proprietary details publicly.

* Submit your details via our **[Adoption Registration Form](https://forms.gle/placeholder)** *(or open a confidential inquiry via project maintainers)*.
